# 荣悦 E5：带屏幕控制的 OpenWrt 随身网络

这次把一台荣悦 E5 做成了可以直接在机身屏幕上管理的 OpenWrt 随身网络设备：连接它的 Wi-Fi 热点即可上网，屏幕能查看网络、信号、流量和设备状态。新增的 OpenClash 页面可以直接切换四种分流模式、选择代理节点，并手动查看 HTTPS 延迟。设备同时保留 Android，完成安装后，日常在两套系统间切换不需要接电脑或重新刷机。目前已完成这台设备的联网、热点和主要操作验证，短信与长期存储稳定性仍在继续验证。

状态截至 **2026 年 10 月 20 日**。这是基于 [Enceka/e5-linux](https://github.com/Enceka/e5-linux) 方案完成的单机实践，包含本地适配、屏幕应用和系统切换入口。

![荣悦 E5 项目界面总览](images/e5-interface-overview.png)

## 现在能做什么

- **提供蜂窝 Wi-Fi 热点。** 当前使用联通 SIM2 上网。现场测试中，另一台手机关闭自身移动数据、连接 E5 热点后，可以访问百度和 Google。
- **直接查看设备状态。** 概览展示网络连接、热点、流量速率、电量、内存和温度；信号页展示网络制式、频段及信号指标；流量页展示当日、本月和历史用量。
- **在机身屏幕上操作 OpenClash。** 通过触摸或方向键、确认键查看运行状态，选择分流模式和节点，手动测试节点的 HTTPS 延迟。
- **保留 Android 与 OpenWrt 两套系统。** 默认启动可按使用需要设置；本机当前以 OpenWrt 为日常默认系统。

## OpenClash：把常用操作放到屏幕上

在设备的“应用 → OpenClash”中，可以看到核心运行状态、当前模式和所选节点。

| 模式 | 对新连接的处理 |
| --- | --- |
| 直连 | 外网流量直接连接 |
| GFW | 规则名单内走代理，其余直连 |
| 大陆白名单 | 国内域名和中国 IP 直连，其余走代理 |
| 全局 | 外网流量统一通过所选代理节点 |

当前使用大陆白名单模式。模式和节点选择会保存，并通过现有核心接口生效，无需重启设备；已经建立的连接可能继续使用原路径。

“测试全部”会分别请求 HTTPS 探测地址，显示每个节点的毫秒延迟及最近测试时间。它测的是请求延迟，不是下载带宽，也不会自动替用户切换节点。当前接入的两条节点已分别完成延迟请求、选择切换和联网验证。

## 两套系统怎样切换

**OpenWrt → Android：** 在 E5 屏幕进入“高级 → 系统 → 切换到 Android”，确认后重启。也可通过 OpenWrt 管理网页完成。

**Android → OpenWrt：** Android 开机并解锁后，打开 **Magisk → 模块 → E5 系统切换 · 进入 OpenWrt → 操作**，等待重启和网络恢复。Android 侧使用 Magisk 模块入口，两边的操作界面并不相同。

本机当前默认 OpenWrt。主动切到 Android 后会保持 Android，方便继续使用；通过上述 Magisk 入口回到 OpenWrt 后，会恢复默认 OpenWrt。上述日常切换不需要电脑、TF 卡或重新刷镜像；首次安装、维护和故障恢复仍是单独的工作。

| OpenClash 模式、节点与延迟功能 | 已完成实机功能测试；用户已确认机身屏幕显示正常 |
| 系统往返切换、OpenWrt 默认及普通重启 | 已验证 |

## 实现基础

本机软件组合包括 OpenWrt 25.12.5、[OpenClash](https://github.com/vernesong/OpenClash) v0.48.002、[Mihomo](https://github.com/MetaCubeX/mihomo) v1.19.32、OpenClash 屏幕应用 1.1.1-local，以及通过 [Magisk](https://github.com/topjohnwu/Magisk) 提供的本机系统切换模块 1.0.2-local。屏幕应用与切换适配建立在上游项目已有能力之上。
