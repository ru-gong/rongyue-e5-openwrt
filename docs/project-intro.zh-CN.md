# 荣悦 E5：在机身屏幕上管理网络

[English](project-intro.en.md) · [项目首页](../README.md)

荣悦 E5 OpenWrt 项目将随身 Wi-Fi、屏幕网络管理和双系统切换整合到一台设备中。手机、电脑连接 E5 热点即可共享蜂窝网络；机身屏幕可以查看信号和流量，也可以直接调整 OpenClash 分流模式、选择代理节点、测试 HTTPS 延迟。设备保留 Android，通过重启可在 Android 与 OpenWrt 之间切换，完成安装后的日常切换无需电脑或重新刷机。

![荣悦 E5 屏幕界面总览](images/e5-interface-overview.png)

## 查看网络与设备状态

概览页集中展示网络连接、热点、流量速率、电量、内存和温度。信号页展示网络制式、频段和信号指标，流量页展示当日、本月及历史用量。

## 直接在屏幕上调整 OpenClash

打开 **应用 → OpenClash**，即可查看核心运行状态、分流模式和当前代理节点。通过触摸或方向键、确认键，可以完成三类操作：

1. **切换分流模式。** 支持直连、GFW、大陆白名单和全局四种模式。
2. **选择代理节点。** 选择会自动保存并应用，无需重启设备。
3. **测试节点延迟。** 点击“测试全部”，查看各节点的 HTTPS 请求延迟、测试结果和测试时间。

| 模式 | 分流方式 |
| --- | --- |
| 直连 | 直接连接目标地址，不使用代理节点 |
| GFW | 命中 GFW 域名列表的请求走代理，其余直连 |
| 大陆白名单 | 命中中国域名或 IP 规则的请求直连，其余走代理 |
| 全局 | 使用全局代理模式，通过所选代理节点转发 |

GFW 和大陆白名单模式均优先直连本地域名与私网请求。模式调整同样会保存，无需重启设备。延迟测试用于比较节点对探测地址的响应时间，不自动切换节点。

## 在 Android 与 OpenWrt 之间切换

- **进入 Android：** 在 OpenWrt 的机身屏幕选择 **高级 → 系统 → 切换到 Android**，确认后重启。
- **返回 OpenWrt：** 在 Android 中打开 **Magisk → 模块 → E5 系统切换 · 进入 OpenWrt → 操作**，随后重启进入 OpenWrt。

日常切换不需要电脑、TF 卡或重新刷入镜像；切换期间热点会断开，需等待系统启动与网络恢复。

项目基于 [Enceka/e5-linux](https://github.com/Enceka/e5-linux) 和 [Enceka/infoscreen](https://github.com/Enceka/infoscreen)，增加 OpenClash 屏幕操作与本机系统切换适配。仓库提供插件源码、开发过程和脱敏实现参考。
