# 荣悦 E5：在机身屏幕上管理网络

[English](project-intro.en.md) · [项目首页](../README.md)

荣悦 E5 OpenWrt 项目把随身 Wi-Fi、屏幕网络管理和双系统切换整合到一台设备中。连接 E5 热点即可共享蜂窝网络；机身屏幕可以查看信号和流量，也能直接调整 OpenClash 分流模式、选择代理节点、测试 HTTPS 延迟。OpenWrt 运行在 TF 卡上，内部存储中的 Android 同时保留，两套系统可在设备上通过重启切换。

![荣悦 E5 屏幕界面总览](images/e5-interface-overview.png)

## 网络状态与热点管理

概览页集中展示连接、热点、速率、电量、内存和温度；信号页展示网络制式、频段和信号指标；流量页展示当日、本月及历史用量。

热点页支持修改密码并更新二维码，查看连接设备、上传下载累计与速率、连接或观察时长，并提供踢下线、拉黑和解除操作。保存新密码会重新初始化无线接口，客户端需重新连接。设备统计从发现连接后开始，含本地和代理通信，重启清零，不替代运营商账单。

## 直接在屏幕上调整 OpenClash

打开 **应用 → OpenClash**，通过触摸或方向键、确认键完成模式切换、节点选择和手动延迟测试。模式与节点选择会保存并应用，无需重启设备。

| 模式 | 分流方式 |
| --- | --- |
| 直连 | 直接连接目标地址，不使用代理节点 |
| GFW | 命中 GFW 域名列表的请求走代理，其余直连 |
| 大陆白名单 | 命中中国域名或 IP 规则的请求直连，其余走代理 |
| 全局 | 使用全局代理模式，通过所选代理节点转发 |

GFW 和大陆白名单模式优先直连本地域名与私网请求。点击 **测试全部** 可查看节点的 HTTPS 请求延迟和测试时间；结果用于比较对探测地址的响应，不会自动切换节点。

## Android 与 OpenWrt 双系统

在 OpenWrt 屏幕选择 **高级 → 系统 → 切换到 Android**，即可重启进入 Android。返回时长按 Android 电源键，在原菜单下方点击 **返回 OpenWrt / 设为默认系统**，确认后开始检查并自动重启。返回成功后，普通重启默认进入 OpenWrt。

![Android 电源菜单附加入口](images/e5-android-power-menu.png)

新的进度页显示实际阶段和已用时间，关闭后可重新打开查看同一任务。日常切换无需电脑或重新刷机，但 OpenWrt 依赖已适配的 TF 卡。返回检查可能持续数分钟；本机一次约 11 分钟，应保持供电并等待自动重启，不要重复点击或手动重启。

## 项目与开源信息

本项目基于 [Enceka/e5-linux](https://github.com/Enceka/e5-linux) 和 [Enceka/infoscreen](https://github.com/Enceka/infoscreen)，使用 OpenClash、Mihomo 与 Magisk，增加屏幕控制、TF 启动适配及 Android 电源菜单入口。仓库提供源码、开发过程和脱敏参考；公开启动与切换脚本默认拒绝设备操作，不是通用刷机包。
