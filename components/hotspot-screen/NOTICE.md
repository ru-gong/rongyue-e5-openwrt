# E5 hotspot screen plugin

see the included LICENSE.

This plugin uses the existing API v2 SDK and host from Enceka's E5 infoscreen:
https://github.com/Enceka/infoscreen

The host integration helper contains limited HTML/JavaScript anchors from
that MIT-licensed host. Copyright (c) 2026 Enceka; its license text is retained
at ../../LICENSES/MIT-Enceka.txt in the source repository. The helper is not
bundled into the plugin archive.

Separately installed OpenWrt, hostapd, UCI, ucode and nftables provide the
runtime APIs. The plugin archive does not include those programs, their
binaries, upstream SDK/host files, firmware, hotspot credentials, QR codes,
client identities or device logs.
