# E5 OpenClash screen plugin

Copyright (c) 2026 ru-gong. The local plugin implementation is MIT-licensed;
see the included LICENSE.

This plugin uses the existing API v2 SDK and host from Enceka's E5 infoscreen:
https://github.com/Enceka/infoscreen

It controls separately installed OpenClash and Mihomo services:

- OpenClash v0.48.002: https://github.com/vernesong/OpenClash — MIT.
- Mihomo v1.19.32: https://github.com/MetaCubeX/mihomo/tree/v1.19.32 — GNU GPL v3.

The SDK, host, OpenClash package, Mihomo binary, proxy definitions, and credentials
are not included in this plugin archive. Their authors retain their own rights
and licenses. This integration is an independent project.
